# 🗺️ Guilda dos Caçadores de Tesouros

> Uma aplicação web interativa com temática de RPG e aventura, projetada para gerenciar missões, recompensas e caçadores de forma dinâmica.

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido com foco na aplicação prática de **JavaScript moderno (ES6+)**, manipulação avançada do DOM e estruturação de interfaces temáticas. A aplicação une lógica de programação e criatividade visual para simular o painel de controle de uma guilda de aventureiros.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica e organização das seções da interface.
* **CSS3:** Estilização temática, design responsivo e identidade visual imersiva.
* **JavaScript (ES6+):** Lógica interativa, manipulação dinâmica do DOM, gerenciamento de estados e eventos de usuário.
* **Git & GitHub:** Controle de versão e hospedagem do código.

---

## ⚙️ Funcionalidades
* **Gerenciamento de missões:** Permite visualizar e interagir com diferentes tarefas/missões disponíveis na guilda.
* **Interface Temática:** Design imersivo voltado para o universo de jogos de fantasia.
* **Atualização em tempo real:** Manipulação fluida de elementos visuais através de interações com o mouse e teclado.
* **Responsividade:** Layout adaptável para diferentes tamanhos de tela.
